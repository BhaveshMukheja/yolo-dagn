# Post-Processing

The prediction outputs generated by the YOLOv11x-OBB model contain multiple types of detections, including:

* genuine dual nuclei candidates
* isolated foreground stars
* galaxy-star overlap cases

To improve the quality of the final DAGN candidate catalog, the repository applies a two-stage post-processing pipeline.

The workflow is:

1. Remove pure star-only detections
2. Remove galaxy-star overlap detections
3. Generate the final dual-nuclei candidate catalog

---

## Input Requirements

The post-processing pipeline expects prediction labels generated during inference:

```text id="9pw8m8"
results/finalModel/predictions/
└── labels/
```

Each `.txt` file corresponds to one SDSS object and contains YOLO OBB detections.

The pipeline also requires the original test CSV:

```text id="z0om2m"
data/finalModel/test/test.csv
```

---

# Step 1 — Remove Star-Only Detections

This step removes detections where all predicted objects belong exclusively to the `star` class.

The script scans every prediction label file and checks whether:

* all detections are class `1`
* no dual nuclei detections are present

These detections are treated as foreground stellar contaminants.

## Logic

A label file is removed if:

```text id="hpbjlwm"
ALL detections == class 1
```

Where:

* `class 0` → dual_nuclei
* `class 1` → star

---

# Step 2 — Remove Galaxy-Star Overlaps

After removing pure star detections, some images still contain overlapping detections between:

* dual nuclei candidates
* foreground stars

These overlap cases are filtered geometrically using polygon intersection tests.

---

## Script

[src/post-process/remove_overlap.py](../src/post-process/remove_overlap.py)


---

## Run Command

```bash id="4l5a4q"
python src/post-process/remove_overlap.py
```

---

## Method

The script:

1. Parses YOLO OBB coordinates
2. Converts detections into polygons using Shapely
3. Separates:

   * class `0` polygons
   * class `1` polygons
4. Checks polygon intersections
5. Removes objects with non-zero overlap area

---

## Overlap Condition

An object is removed if:

```text id="5em7u7"
intersection_area > 0
```

between:

* dual nuclei polygon
* star polygon
